# Third-party code

Animation Composer is distributed under GPL-3.0. It does not include game assets or downloaded moveset assets.

- **HKX2Library**, Katalash / ret2end and contributors, MIT. Vendored from the copy in `lennart99v/SageHavokEditor` at commit `ce065f5f5830461f4282adb4934b35301c7b6f8f`. The vendored license is at `vendor/HKX2Library/LICENSE`. Changes: target .NET 8; suppress existing vendor nullability warnings; accept a zero-capacity header for an empty array while retaining nonempty-array checks. This copy includes the Sage project's Skyrim pointer-size fixes. https://github.com/lennart99v/SageHavokEditor
- **SageHavokEditor HKTransform**, GPL-3.0, same commit. The original uniform-scale transform helper is retained in `vendor/SageAnimation/HKTransform.cs`; its license is adjacent. Since 0.2.0, preview transforms use `BoneTransform.cs` and full affine matrices for nonuniform scale. The original Sage spline decoder was evaluated but is not shipped. https://github.com/lennart99v/SageHavokEditor
- **PyNifly spline algorithms**, BadDogSkyrim and contributors, GPL-3.0. `SplineDecoder.cs` is a C# adaptation of quaternion decoding and spline sampling documented in `io_scene_nifly/hkx/anim_fo4.py`. PyNifly credits Dagobaking's skyrim-fo4-animation-conversion and PredatorCZ/HavokLib. The pinned revision is recorded in `docs/SOURCES.json`. https://github.com/BadDogSkyrim/PyNifly
- **PenguTEX BoundedBsa**, GPL-3.0-only, adapted from the local PenguTEX implementation. Changes: replace project-specific diagnostic/path dependencies; support verified same-offset archive aliases; retain member bounds and decompressed-length checks. https://github.com/opteron-x86/PenguTEX
- **Avalonia**, **K4os.Compression.LZ4.Streams** and their transitive dependencies are installed as NuGet packages. Avalonia and the K4os packages use the MIT license; the Inter typeface uses the SIL Open Font License. Upstream notices are included under `docs/third-party`; packaging also collects notices and metadata from the installed NuGet packages, including the .NET runtime. See the lock files for exact dependencies.

OAR configuration serialization was checked against `ersh1/OpenAnimationReplacer` and the local source checkout. BFCO slot mappings were checked against the framework's author documentation and MCO-to-BFCO converter documentation. Those frameworks are required separately and are not bundled.
